VoiceOS

A multi-tenant SaaS platform that enables the creation, configuration, and operation of conversational voice agents 
capable of handling interactions via web, phone, and WhatsApp. These agents query customer data using tools and execute actions, 
supporting natural interruption (barge-in) and context switching mid-conversation. 
The platform supports external and private MCP servers as agent tools. 
Integration is deliberately blocked until enabled within the environment and approved on a per-tool basis.
